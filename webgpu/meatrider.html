meatrider on WebGPU

The Bitcoin-shaped meatrider tier — SHA-256, twice, over an 80-byte block header — in a WGSL compute shader. Two SHA-256 compressions per nonce: the header's first 64 bytes are folded into a midstate on the host, and only the 16-byte tail (12 fixed bytes plus the little-endian nonce) moves. The digest is Bitcoin's display order, so the leading-zero-bit test applies to the bytes exactly as printed.

The page does not trust the GPU. Before mining it hashes known (randomData, difficulty, nonce) triples, compares the GPU digest with a JavaScript implementation of the same header/SHA-256d path, and compares both with vectors generated by tools/meatrider_ref.py. A mined nonce is then re-checked in JavaScript before it is shown as an answer.
