Anubis HashX in WebAssembly: compiled WAT vs the official module

A HashX program is fixed for a whole challenge, so it does not have to be interpreted. The left-hand module is the 512-instruction program emitted as straight-line WAT (tools/gen_hashx_wat.py); the right-hand ones are the modules Anubis actually ships. Same challenge, same nonces, same work — only the execution strategy differs.
